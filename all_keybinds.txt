              (scripts/uosc/lib/menus.lua:701 get_keybinds_items 用 table.sort 按 cmd 排)
 数据来源   : mpv 启动时 input 模块 trace 日志（即 mpv 真实加载到的绑定）

【怎么读】
 序号  命令                                      键位             来源            中文说明
  ──   一行一条，和 Ctrl+i 菜单从上到下逐条对齐；最后一列是人工注释，可以直接读。
 来源三种：
   内置        = 编译进 mpv.exe 的默认键位，配置文件目录里搜不到
   config:N    = 你在 portable_config\input.conf 第 N 行写的
   脚本: 名字  = 某个脚本运行时注册的
 中文说明里的括号标记：
   （不弹提示）      = 命令带 no-osd，动作照常执行，只是不显示屏幕提示
   （仅强制段生效）  = 脚本用 add_forced_key_binding 注册，平时按了没反应
   （屏蔽…）        = ignore，故意占掉这个键位让它失效
 连击(chord) g-x = 先按 g、再在 2 秒内按 x（不是同时按）。
 方向约定（正负号含义，来自 mpv 官方选项文档）：
   pan-x  正 = 画面右移（视角左移）         pan-y  正 = 画面下移（视角上移）
   align-x -1 左 / 0 中 / 1 右              align-y -1 上 / 0 中 / 1 下
   zoom / scale 正 = 放大                   panscan 正 = 裁掉更多画面
   video-rotate 正 = 顺时针                 sub-pos 正 = 字幕下移（本配置 sub-pos=92）
   audio-delay / sub-delay 正 = 延后

【重要】
 1. uosc 自己的 11 条鼠标/滚轮内部事件 (uosc/__keybinding1..11) 被 uosc 用
    owner ~= 'uosc' 排除了，Ctrl+i 里看不到，所以这里也没有。
 2. 标了「强制段」的（SimpleHistory 全部 4 条、mpvacious 的 export-note）平时按了没反应，
    中文说明里也会标「（仅强制段生效）」。
 3. mpv 里 a 和 A、g 和 G、t 和 T 是两个不同的键（大写要按 Shift）。
    例：#094 t / #095 T 都是切置顶；#233 o / #234 P 都是显示进度条。
